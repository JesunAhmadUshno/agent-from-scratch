# 0001: Code stays in its stage folders

Date: 2026-11-08. Status: accepted. Decided by: Jesun Ahmad Ushno.

## Context

The portfolio standard v2 puts code in src/, evidence in experiments/
and scores in results/, but allows domain-named folders listed in the
README. Here each stage folder (level-1-learn, level-2-build,
level-3-deep) holds the agent, its runner, its task suite and its
results file. Level 2 loads Level 1's tools by path, Level 3 builds on
Level 2, the tests, CI, the dashboard and its JavaScript parity check
read these paths, and the released tarballs v0.1, v0.5 and v1.0 and
the fan-out drafts cite them.

## Decision

Keep the three folders and their file names. The README layout table
maps each file to its role: code, evidence (task suites written before
each run, timing), results (results_*.json, regenerated by the runners;
CI fails on any difference).

## Consequences

No path breaks and the migration moves documents only. The folder
names still read as the old ladder; a later move to src/,
experiments/ and results/ would need the path loader in
level-2-build/agent_build.py, the tests, CI and site/ changed in one
pull request.
