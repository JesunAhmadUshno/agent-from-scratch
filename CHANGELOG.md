# Changelog

All notable changes to this project. Format: Keep a Changelog 1.1.
Versions follow Semantic Versioning. The tags v0.1, v0.5 and v1.0 are
the releases of the old Learn, Build and Deep levels; under the
portfolio standard v2 the verdict is Functional, not v1.0 Released.

## [Unreleased]

### Changed
- 2026-11-08: Adopted the portfolio standard v2. README is the
  abstract (question, headline with its interval, field, job family,
  verdict: Functional, not pre-registered), with one-command reproduce,
  lifecycle and layout. PROPOSAL.md gathers SPEC.md, DOSSIER.md,
  NOVELTY.md, BUILD-SPEC.md and DEEP-SPEC.md; REPORT.md gathers the
  three level write-ups, the old benchmark table,
  docs/research-review.md and the ROADMAP.md backlog; ROADMAP.md's
  shipped list is this file. Grades and rubric scores left the public
  files (they are internal). PUBLICITY.md moved to docs/publicity.md.
  Code stays in its stage folders (decision 0001).
- 2026-11-08: CI runs with read-only token permissions, discovers every
  test, and runs a layout test (required files, no public grade).
  CodeQL now also scans the dashboard's JavaScript; Dependabot watches
  the dashboard's npm packages.
- 2026-11-08: The dashboard reads the verdict from README.md and the
  threats and backlog from REPORT.md, and no longer shows a grade.

## [1.0] - 2026-11-05

### Added
- Deep (compressed): self-critique loop with an independent
  deterministic critic, bounded revision (MAX_CRITIQUE_ROUNDS = 2),
  per-task critique logging, and a 32-task scored evaluation suite
  reporting success without critique (0.5357) versus with critique
  (1.0) on the same suite.

## [0.5] - 2026-11-05

### Added
- Build: plan-then-execute agent, persistent JSON memory, four
  recovery strategies, at most one replan.

## [0.1] - 2026-11-05

### Added
- Learn: deterministic tool-using agent loop.

Upgrade path: there is no installed package; users clone the repo.
Results files are regenerated by the runners, so after any upgrade
re-run the Reproduce line in README.md, which fails if a result moved.
